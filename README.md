# DentFlow Pro (Dental Clinic OS) | دليل التشغيل والتوثيق الشامل

نظام إدارة عيادة الأسنان المتكامل فائق الأمان والسرعة، مبني وفق أحدث معايير هندسة البرمجيات بالواجهة العربية الكاملة (RTL) مع التزام صارم بجميع قواعد العمل الطبية والمالية.

---

## 1. بيانات تسجيل الدخول الافتراضية (Default Accounts)

| الحساب | اسم المستخدم | كلمة المرور | الدور الوظيفي | الصلاحيات |
| :--- | :--- | :--- | :--- | :--- |
| **الطبيب (Doctor)** | `doctor` | `doctor123` | `DOCTOR` | وصول كامل لكافة السجلات + **اللوحة المالية الحصرية** |
| **المساعد (Assistant)** | `assistant` | `assistant123` | `ASSISTANT` | إدارة الطابور، الكشوفات، السندات (ممنوع من التقارير المجمعة 403) |

> 💡 **ميزة إضافية:** يوجد زر فوري بالأعلى `تبديل للدكتور / للمساعد` للتبديل التجريبي السريع بين الحسابات لاختبار الصلاحيات بنقرة واحدة.

---

## 2. قواعد العمل والمنطق البرمجي الصارم (Strict Business Rules)

### أ. جدول العمل والشفتات
- **أيام العمل:** من السبت إلى الخميس.
- **يوم الجمعة:** محظور تماماً من الحجز وتظهر رسالة واضحة بأن العيادة مغلقة بالكامل.
- **شفتات السبت، الأحد، الثلاثاء، الأربعاء:**
  - شيفت صباحي: 9:00 ص - 2:00 م
  - شيفت مسائي: 5:00 م - 10:00 م
- **الإثنين والخميس:** **صباحي فقط** (الشيفت المسائي ملغي تماماً نظراً لصيام الطبيب).

### ب. كوتة الفجر / الحالات الفورية (كوتة محجوزة)
- **الشيفت الصباحي:** كوتة محجوزة لـ **7 كشوفات عامة** فقط.
- **الشيفت المسائي:** كوتة محجوزة لـ **3 كشوفات عامة** فقط.
- زر تسجيل فوري `+ كشف فجر / فوري (كوتة)` يستهلك تلقائياً من الكوتة المتبقية ويحدث العداد اللحظي.

### ج. منطق حالات التقويم (Orthodontics Logic)
1. **تركيب تقويم جديد (`ORTHO_NEW_FIT`):**
   - **الحد الأقصى:** حالتان فقط يومياً عبر العيادة بالكامل.
   - **الموعد والشيفت:** الساعة 9:00 صباحاً كأولوية أولى في الشيفت الصباحي حصراً.
   - **الشرط المسبق (Prerequisite):** يجب أن يكون المريض قد خضع مسبقاً لكشف واستشارة عامة/تقويم معتمدة في النظام، وإلا يرفض النظام الحجز مباشرة لحين إجراء الكشف المبدئي.
2. **متابعة تقويم (`ORTHO_FOLLOWUP`):** سعة مرنة موزعة تلقائياً على أرقام التقويم المخصصة.

### د. مولد أرقام الطابور الذكي (Smart Queue Allocator)
توزيع تسلسلي تلقائي للأدوار دون أي تدخل بشري:
- أرقام التقويم المخصصة: `1`، `5`، `10`، `15`، `20`، `25`، `30`...
- أرقام الكشف العام: `2`، `3`، `4`، `6`، `7`، `8`، `9`، `11`، `12`، `13`، `14`...

---

## 3. المحرك المالي الذكي وخصومات VIP (الحبايب)
- `المبلغ الإجمالي الأصلي` (Total Fee)
- `قيمة الخصم` (Discount Amount - VIP / الحبايب)
- `الصافي بعد الخصم` = المبلغ الأصلي - قيمة الخصم
- `المسدد / المدفوع` (Paid Amount)
- `المتبقي` (Remaining Balance) = الصافي - المسدد (محسوب بأمان رياضي لحظي).

---

## 4. نظام الصلاحيات والأمان (RBAC)
- **المساعد (الاستقبال):** يدير الطابور، يسجل الحضور، يصدر سندات القبض الفردية، ويطلع على متبقيات المريض الفردي فقط. محظور تماماً من رؤية الدخل الإجمالي (`HTTP 403 Forbidden`).
- **الطبيب:** وصول كامل للوحة التحليلات المالية:
  - إجمالي الدخل اليومي والمحصل الفعلي.
  - تفصيل الإيرادات حسب الشيفت (الصباحي مقابل المسائي).
  - تفصيل الإيرادات حسب التخصص (كشوفات عامة مقابل تقويم).
  - إجمالي المتبقيات المعلقة والديون طرف المرضى.
  - إجمالي خصومات VIP الممنوحة.
  - دفتر اليومية المالي المباشر للمعاملات النقدية.

## 5. التشغيل المحلي (Local Execution Commands)

### تشغيل خادم الباك إند (Django REST API):
```powershell
.\venv\Scripts\python backend/manage.py runserver 127.0.0.1:8000
```

### تشغيل واجهة المستخدم (React + Vite):
```powershell
cd frontend
npm run dev
```

الرابط المباشر للواجهة: `http://localhost:5173/`
